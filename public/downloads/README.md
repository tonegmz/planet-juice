Put the free 7-day meal plan PDF here as `7-day-meal-plan.pdf`.

People who sign up on the site get an email with a link to
https://www.planetjuice.shop/downloads/7-day-meal-plan.pdf

To host the PDF somewhere else (Google Drive, Dropbox), set the
`MEAL_PLAN_URL` environment variable in Netlify to that link instead.
